# AI Financial Performance Dashboard

## Project Overview
An interactive financial dashboard designed to help small businesses analyze their financial performance.

## Features
- Upload financial data in CSV or Excel format
- Calculate total revenue
- Calculate total expenses
- Calculate total profit
- Visualize revenue and expenses
- Display monthly profit trends
- View financial records

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly

## How to Run
1. Install the required packages:
   pip install -r requirements.txt

2. Run the application:
   streamlit run app.py
